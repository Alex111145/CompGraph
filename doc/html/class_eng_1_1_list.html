Detailed Description

List of the nodes to render, each one with its final matrix in world coordinates. It is filled by visiting the scene graph (pass), lights first and meshes after, then rendered in this order.

◆ pass()

void ENG_API Eng::List::pass ( const Node * node,
const glm::mat4 & parentMatrix = glm::mat4(1.0f) )

Visits a node and, recursively, its children (depth-first). The world matrix of each node is the world matrix of its parent multiplied by its own matrix. Lights go to the front of the list, meshes to the back, other nodes (root, cameras) are not added.

Parameters
nodenode to visit (nullptr = nothing to do)
parentMatrixworld matrix of the parent (identity for the root)
