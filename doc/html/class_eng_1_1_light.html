Detailed Description

Scene graph node that emits light. Its position and direction come from its matrix: the light sits at the origin of the node and points along its -Z axis.

Main types of light.

Enumerator

Infinite light, all rays parallel (e.g. the sun).

OMNI 

Point light, same light in all directions (e.g. a candle).

SPOT 

Light with a cone of effect (e.g. a flashlight).

void ENG_API Eng::Light::render ( const glm::mat4 & modelViewMatrix) const
overridevirtual

Loads the modelview matrix and passes the light settings to OpenGL, then switches the light on. Directional: position with w = 0. Omni: position with w = 1 and cutoff 180 (special value). Spot: w = 1 and its cutoff.
