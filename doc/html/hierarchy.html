This inheritance list is sorted roughly, but not completely, alphabetically:
 CEng::BaseBase engine main class (singleton): owns the window and the rendering context, reads the input and renders a render list. The libraries used for these tasks stay hidden inside the engine
 CEng::LoaderConverts the nodes, meshes, materials, textures and lights of a file into engine objects
 CEng::ObjectAbstract base class of everything the engine can render (nodes, materials, textures, lists)
  CEng::ListFlat list of the lights and meshes of a scene graph. The lights are drawn before the meshes, so that every mesh is lit by all of them. The list does not own the nodes
  CEng::MaterialAmbient/diffuse/specular/emission colors, shininess and optional texture
  CEng::NodeGeneric element of the scene graph. Every node has a local matrix relative to its parent
   CEng::CameraScene-graph node that is a camera. Its world matrix places it in the scene, the view matrix is the inverse of that world matrix
   CEng::LightAbstract scene-graph node that is a light. The homogeneous local position decides the type: w = 0 directional (xyz = direction towards the light), w = 1 point light
    CEng::DirectionalLightLight infinitely far away (like the sun): only its direction matters. The light comes from the +Z axis of the node, so the rays travel along -Z, like a camera looks
    CEng::PointLightLight placed in a point (like a bulb), weaker with the distance
   CEng::MeshScene-graph node holding triangles (positions, normals, texture coordinates) and a material
  CEng::Texture2D image applied to the surfaces through their texture coordinates
 CEng::Base::ReservedBase class reserved structure (PIMPL): hides FreeGLUT from the engine users
