Detailed Description

Material painted with a 2D image. The image is loaded only once into the memory of the graphics card, when the texture is created; then each render() only binds it again. The image is released when the texture is deleted.

Constructor & Destructor Documentation

◆ Texture()

ENG_API Eng::Texture::Texture ( const std::string & name,
int width,
int height,
const unsigned char * bitmap )

Constructor: creates and configures the texture, then loads the image into it. This is done only once: the image stays in the memory of the graphics card and render() only binds it again. Texture coordinates outside [0, 1] repeat the image; linear filtering is used both when the image is enlarged and when it is reduced.
