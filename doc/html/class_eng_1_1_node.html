Detailed Description

Scene graph node: has its own matrix (relative to the parent), one parent and a list of children. The node does not take ownership of its children.

std::vector<Node *> Eng::Node::children

Child nodes.

Warning
std::vector moves its elements in memory when it grows: pointers and references to its elements become invalid. Here it stores only pointers to the nodes (the nodes themselves never move); if this ever gives problems, use std::list, which never moves its elements.
