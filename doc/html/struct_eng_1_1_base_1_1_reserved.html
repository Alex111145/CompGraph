◆ loadLight()

Eng::Light * Eng::Base::Reserved::loadLight ( const aiLight * fileLight)

Converts a light of the file into an engine light. Directional, point and spot lights are supported. The diffuse and specular colors are scaled so that the brightest component is at most 1 (a file can store colors multiplied by an intensity). The ambient color stays black: glTF lights have no ambient term (the scene ambient is the global one of OpenGL).

◆ loadMaterial()

Eng::Material * Eng::Base::Reserved::loadMaterial ( const aiMaterial * fileMaterial)

Converts a material of the file into an engine material. Diffuse, specular and emission colors and shininess are copied when the file has them (otherwise the default values of Material stay). Ambient: the color of the file if there is one, otherwise 0.2 times the diffuse color (glTF has no ambient color).

◆ loadNode()

Eng::Node * Eng::Base::Reserved::loadNode ( const aiScene * fileScene,
const aiNode * fileNode,
const std::vector< Material * > & materials )

Converts a node of the file into an engine node and, recursively, its children. The node becomes a Light if a light of the file has its name, a Mesh if it has one mesh, otherwise a Node (with one child Mesh for each of its meshes). The matrix of the node, relative to its parent, is copied: Assimp stores it by rows, GLM by columns, so it is transposed.
